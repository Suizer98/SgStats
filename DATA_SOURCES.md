# Data sources

## Sources

| Source | Provider key | Access | Format | Notes |
| --- | --- | --- | --- | --- |
| Data.gov.sg | `datagov` | `data.gov.sg/api/action/datastore_search` plus the v2 metadata API | JSON API | About 4,000 datasets indexed in `backend/data/datagov_index.json`. Up to 10,000 rows per fetch. |
| SingStat Table Builder | `singstat` | `tablebuilder.singstat.gov.sg/api/table/tabledata/{id}` and its search API | JSON API | Searched live per query. Tables have nested series with period columns. |
| Mock internal database | `internal` | `backend/data/internal/sector_hiring.xlsx` | Excel | Synthetic sector hiring figures for 2019-2025. Clearly labelled as mock in the title, agency, note and citation. Generated by `scripts/make_internal_data.py`. |
| Bundled snapshots | same as origin | `backend/data/snapshots/` | JSON and CSV | Real records captured from the live APIs on 2026-09-26 for the three pinned datasets. Used only when a live fetch fails. Refresh with `scripts/refresh_snapshots.py`. |

The platform therefore handles four input formats: JSON from both government APIs, CSV (the Data.gov.sg employed residents snapshot, stored the way Data.gov.sg offers downloads), Excel (the internal source) and API responses in general.

## Normalisation

Every source is reduced to the same long format:

| Column | Meaning |
| --- | --- |
| `period` | `2024`, `2024-H1`, `2024-Q3` or `2024-07` |
| `grain` | year, half, quarter or month |
| `series` | Human-readable series label, for example `Information & Communications` |
| `measure` | Unit or measure name, for example `Thousand` or `Per Cent` |
| `value` | Float |

The normaliser recognises three shapes:

- Wide tables with one column per period, as used by many Data.gov.sg and SingStat tables. Indented labels are children of the last unindented label, and rows in later sections are renamed with the section, for example `Services (Employed Residents Aged 15 - 19 Years)`, so breakdowns are not mixed into headline totals.
- Long tables with a time column, one or more label columns and numeric columns. The time column is the one where at least 80% of values parse as periods. Measure columns are ranked by relevance to the query.
- SingStat nested rows with a `columns` list of `{key, value}` pairs.

## Data quality and cleaning

Each dataset carries a `quality` block that is shown in the Datasets tab, included in the Markdown export and reported by the extractor agent.

| Check | Rule |
| --- | --- |
| Parse accounting | Source records, normalised rows, rows in the requested range and final rows are all reported |
| Missing markers | `na`, `n.a.`, `-`, `..`, `nil`, `s`, `x` and blanks are treated as missing, not as text |
| Numbers | Thousands separators and padding are removed before parsing |
| Nulls | Rows without a numeric value are dropped and counted per column |
| Duplicates | Exact duplicate rows are removed and counted |
| Repeated periods | Several records for one period and series are averaged and the note says how many |
| Outliers | Robust z-score using median and MAD per series; points above 3.5 in series with at least 5 points are flagged, not removed |
| Coverage | Series count, period count and first to last period |
| Required columns | `period` and `value` must exist, otherwise the dataset fails validation and the extractor moves on |
| Range | Rows outside the requested years are dropped; if none remain, the latest available periods are kept and the note says so |

## Statistics

- Latest value and change since the first period. Per-cent series use percentage points. Other series use per-cent change only when the start is positive and the latest value is not negative, otherwise absolute change, so a series that crosses zero never reports a misleading percentage.
- Up to 6 comparable series per chart, chosen by relevance to the query and similar scale, and at most 40 periods.
- Pearson correlation between the lead series and every other series that shares at least 4 periods, including series from other datasets. Variants of one series, such as seasonally adjusted and unadjusted, are skipped. Results are labelled strong (|r| ≥ 0.7), moderate (≥ 0.4) or weak, and the UI notes that correlation is not causation.
- Every charted value, latest value, start value and change is added to the fact list used by the grounding check.

## Citations

Each dataset has a citation string built from the agency, title and dataset id, for example `Singapore Department of Statistics, Employment (Persons) By Sector, (As At Year-End), Annual. SingStat Table Builder M182841.` Snapshot citations add the retrieval date, and internal citations name the workbook. The briefing lists every citation used.
